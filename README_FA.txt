مدیریت معدن - پروژه Android WebView

ساخت APK:
1) فایل ZIP را استخراج و محتویات آن را به مخزن GitHub با نام main منتقل کنید.
2) بخش Actions را باز کنید؛ Workflow با نام Build APK را انتخاب و Run workflow کنید.
3) پس از پایان موفق build، Artifact با نام MineManagement-debug-apk را دانلود کنید و APK داخل آن را نصب کنید.

ساخت Debug APK با Gradle 8.9 و Java 17 از طریق GitHub Actions تنظیم شده است.

این پروژه بسته‌بندی آزمایشی WebView از نسخه HTML است. هنوز اتصال سرور مرکزی امن، احراز هویت/مجوز سمت سرور،
دسترسی GPS و دوربین بومی، تست دستگاه و APK خروجی در این محیط انجام نشده‌اند. APK ساخته‌شده Debug است و برای انتشار رسمی
نیاز به امضای Release اختصاصی دارد.
